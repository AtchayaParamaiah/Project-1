# Registration Form

A simple and responsive registration form built using **HTML, CSS, and JavaScript**.

## Features

* ✅ Name validation
* ✅ Email validation
* ✅ Password validation
* ✅ Password strength indicator
* ✅ Real-time form validation
* ✅ Success message on form submission
* 🎉 Confetti animation after successful registration
* 📱 Responsive design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts

## Project Structure

```text
registration-form/
├── index.html
├── style.css
└── script.js
```

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Fill in the registration form and test the validation.

## Validation

The form checks:

* Name should not be empty.
* Email should be in a valid format.
* Password should meet the required security criteria.
* Password strength is displayed as **Weak, Medium, or Strong**.

## Author

Created as a practice project to learn **form validation and JavaScript DOM manipulation**.
